# The Guild of Merchant Explorers (unofficial web version)

An unofficial fan implementation of *The Guild of Merchant Explorers* for personal play:
four maps (Avenia, Kazan, Aghon, Cnidaria), works offline and installs as an app.

**Play:** https://benderrodrigo.github.io/tgome/

The board game is designed by Matthew Dunstan & Brett J. Gilbert and published by
[AEG](https://www.alderac.com/tgome/). This project is not affiliated with or endorsed by them;
buy the game and read the [official rules](https://www.alderac.com/tgome/).
All artwork here is original (hand-drawn SVG); no publisher artwork is included.

Install: open the link in Chrome on Android and choose *Install app* (or *Add to Home screen*)
from the menu; on a laptop use the install icon in the Edge or Chrome address bar.

Game statistics are stored only in your own browser (localStorage).
